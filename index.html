How to play
  • Arrows rotate a row left/right or a column up/down. Tiles wrap around the edge.
  • Make every row a winning riichi hand: 4 sets + a pair (or seven pairs / kokushi).
  • Teal-framed tiles are open sets (pon/chii). They can't be split: a column arrow on one moves all three columns, and it is blocked if another open set only partly overlaps.
  • Rows with no open sets count as riichi, so any complete shape wins. Rows with an open set need a yaku (yakuhai, tanyao, honitsu, toitoi, …). Each row has its own seat wind; the round wind is shared.
  • The red-outlined last column is the winning tile. It's decoration only.
