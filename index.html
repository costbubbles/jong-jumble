How to play
  • Shift controls: arrows rotate a row left/right or a column up/down (tiles wrap around). Or drag a tile, or hover it and press WASD / arrow keys.
  • Drag & drop controls (Controls menu): click tiles to select an adjacent run in one row, then drag it onto another row to swap, or elsewhere in its row to reorder.
  • Make every row a winning riichi hand, read left to right: sequences ascending (4-5-6), triplets any order, pairs side by side.
  • The red-outlined tile in the Win column is each row's winning tile. It never moves. It completes the one unfinished group in its row, wherever that group is (e.g. 5-6 … → 4). The rest of that group still has to be in order.
  • Grey, smaller tiles are open sets (pon/chii) and can't be split. A column arrow on one moves all three columns, and it is blocked if another open set only partly overlaps.
  • Rows with no open sets count as riichi. Rows with an open set need a yaku (yakuhai, tanyao, honitsu, toitoi, …). Each row has its own seat wind; the round wind is shared.
  • Boxes show valid groups: pairs, triplets, sequences. Bigger hands (more han) score more.
