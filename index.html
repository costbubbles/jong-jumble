    How to play

    • Make every row a winning riichi hand, read left to right: sequences ascending (4-5-6), triplets in any order, pairs side by side. With the Any order tile-order setting, a row wins as soon as it holds the right tiles, in any arrangement.
    • The red-outlined tile in the Win column is each row's winning tile. It never moves. It completes the one unfinished group in its row, wherever that group is (e.g. 5-6 … → 4). That group's own tiles still have to be in order.
    • Shift controls: arrows rotate a row left/right or a column up/down (tiles wrap around). Or drag a tile, or hover it and press WASD / arrow keys.
    • Drag & drop controls: click tiles to select an adjacent run in one row, then drag it onto another row to swap, or elsewhere in its row to reorder.
    • Grey, smaller tiles are open sets (pon/chii) and can't be split. A column arrow on one moves all three columns, and it is blocked if another open set only partly overlaps.
    • Rows with no open sets count as riichi. Rows with an open set need a yaku (yakuhai, tanyao, honitsu, toitoi, …). Each row has its own seat wind; the round wind is shared.
    • Boxes show valid groups: pairs, triplets, sequences; red = tiles the winning tile completes. Bigger hands (more han) score more, and faster solves keep more of the points.
